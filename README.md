# PsychoPy Experiments Repo

So far contains rating experiment for Speech Accent Archive

once you've built the environment & installs with `uv sync`​:

1. You'll need to build a new `conditions_file` per participant:

Change the participant code in the constant `PARTICIPANT` at the top of `scripts/build_conditions_file.py`. 

Then run `python -m scripts.build_conditions_file`. Don't worry, the script won't let you overwrite a conditions file once it's been built.

2. Running the experiment itself:

If starting a new participant, change the participant code in the constant `PARTICIPANT` at the top of `scripts/runner.py`.

To start a new participant or to continue rating for a participant if all the sessions haven't been completed yet, run `python -m scripts.runner`. 

Without the `-m` flag it will complain about imports. 

The script will pick up from left off sessions (that's the main use of the session logs). Results are stored in the results file. Once all the files listed in the conditions file for a particpant, launching an experiment will result in a "All sessions complete" message. 

Instructions for the experiment are in the pop-up window generated by launching the experiment. Enjoy!
